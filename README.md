# Reglas de notificación

Prueba técnica desarrollada con Angular y PrimeNG para configurar reglas con disparadores, condiciones y acciones.

## Requisitos

- Node.js y npm instalados, compatibles con Angular 22.

## Ejecutar el proyecto

Desde la carpeta del proyecto, instala las dependencias:

```bash
npm install
```

Inicia el servidor de desarrollo:

```bash
npm start
```

Abre [http://localhost:4200](http://localhost:4200) en el navegador.

Para detener el servidor, presiona `Ctrl + C` en la terminal.

## Datos de prueba

Las reglas se cargan desde `public/mock.json`. No necesitas levantar un backend. Los cambios realizados en la interfaz no se guardan en ese archivo.

## Compilar

```bash
npm run build
```

Los archivos compilados se generan en `dist/ReglasNotificacion/`.
